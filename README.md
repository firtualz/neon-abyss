NEON ABYSS — Echoes of the Last Star: a roguelite arena shooter. Pilot the ship Echo through ten waves of the void, pick an upgrade card after every cleared wave, break the VOID MAW boss on waves 5 and 10, and relight the last star. Five enemy types, dash with i-frames, synthesized WebAudio sound, no libraries, no network — just open it and fly.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 — WASD to fly, mouse to aim, hold click or Space to fire, Shift to dash, 1/2/3 to pick upgrades, P to pause, M to mute.
